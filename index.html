FAQ

Answers to common questions

Where is my data stored? Is it secure?

Everything runs on your own servers. Messages, files and user data live in your own PostgreSQL database and never pass through a third party — you own 100% of your data.

What are the limits of the Free plan?

Free includes full text, image, file and voice messaging plus contacts and group chat. It does not include audio/video calls, extensions (mini-app container, plugins) or the admin console. Upgrade to Pro to unlock them.

What's the difference between Pro and Enterprise?

Pro ships a compiled build you can deploy directly, with calls and extensions enabled. Enterprise adds the complete frontend and backend source code so you can customize freely and white-label the product.

Can I pay with USDT? How does it work?

Yes — USDT on TRC-20 or ERC-20. After you submit your request we provide a wallet address and order ID; once the transfer is confirmed on-chain we deliver within 24 hours and can issue a receipt.

Which platforms are supported?

Web, Android, iOS, Windows and macOS. One Flutter codebase ships to every platform with consistent features, and CI builds each release automatically.

Is deployment complicated?

Not really. The backend is a single ASP.NET Core service plus PostgreSQL (docker compose starts the database in one command), and CI produces the client artifacts, so routine ops work is enough.
